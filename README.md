## Practical Labs Completed

### Day 01 – Linux Fundamentals

- Verified AlmaLinux operating system and version.
- Identified hostname and system information.
- Practiced user identification using `whoami` and `id`.
- Inspected logged-in sessions using `who`.
- Explored Linux directories using `pwd` and `cd`.
- Listed files and hidden files using `ls`, `ls -l`, `ls -a` and `ls -la`.
- Checked kernel information using `uname`.
- Practiced Linux root password recovery using GRUB and `rd.break`.
